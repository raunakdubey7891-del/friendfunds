## ✨ Overview

FriendFunds replaces awkward "can you lend me some money?" conversations with a clear, structured process. Borrowers post a loan request, friends fund it, and repayment follows a transparent monthly schedule, so everyone knows exactly where they stand.

## 🚀 Features

| | |
|---|---|
| 📝 **Loan Requests** | Borrow ₹1,000 – ₹1,00,000 over 6, 12, 18 or 24 months |
| 📈 **Invest & Earn** | Browse requests and fund them at a fixed 8% annual return |
| 📅 **Monthly Installments** | Predictable, automated repayment schedule |
| 🪪 **KYC & Agreements** | Aadhaar and signed undertaking upload before a loan goes live |
| 💳 **Secure Payments** | Checkout via Razorpay (cards, UPI, net banking) |
| 📊 **Personal Dashboard** | Track borrowed loans, investments, profile and documents |
| 📱 **Responsive UI** | Works smoothly on desktop and mobile |

## 📋 Loan Terms

- **Interest:** 8% per annum, fixed
- **Repayment:** Monthly installments
- **Late fee:** 2% on overdue amounts
- **Prepayment:** No penalty

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, vanilla JavaScript (ES modules)
- **Backend / Storage:** Supabase
- **Payments:** Razorpay
- **Hosting:** Vercel

## ⚡ Getting Started

```bash
# Clone the repository
git clone https://github.com/raunakdubey7891-del/friendfunds.git
cd friendfunds

# Serve locally (ES modules need a server, not file://)
npx serve .
```

Then open the local URL shown in your terminal.

> **Note:** Add your own Supabase and Razorpay keys in `script.js` to enable data storage and payments.
